# Student Registration System (JavaScript DOM Manipulation)

This is a simple **Student Registration System** built using **HTML, CSS, and JavaScript**.  
It allows users to register student details, view them in a table,   
The system uses **localStorage** to persist data even after page refresh.

---
 
  - ## Project: Student Registration System
  - GitHub Repo Link: https://github.com/anuj-web-stack/Student-Registration-System.git

## Features
  - **Register New Students**
  - Name (only alphabets allowed )
  - Student ID (numeric only )
  - Email (valid format )
  - Contact Number (exactly 10 digits )

  -  **Edit Existing Student Records**  
  -  **Delete Records**  
  -  **Persistent Data with localStorage** (data will not be lost on refresh)  
  -  **Student Count Display** (updates dynamically)  
  -  **Responsive UI**
  - Desktop (≥ 1025px)  
  - Tablet (641px – 1024px)  
  - Mobile (≤ 640px)  

  - **Dynamic Vertical Scrollbar** (appears only when records exceed visible height)  
  - **Row Highlight Animation** for newly added students
